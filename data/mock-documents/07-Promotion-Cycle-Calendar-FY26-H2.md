## 1. How to use this calendar

Promotion cycles are two-week trading periods starting on Thursdays. Standard, Local and Event promotions start on a cycle start date and end on a cycle end date. Cut-offs are the dates by which a request must be **approved** for the stated execution route. Dates are inclusive.

## 2. Cut-off rules (effective for C21 onward)

| Execution route | Cut-off | Counted from |
|---|---|---|
| Leaflet inclusion (print) | **21 calendar days** before cycle start | Cycle start date |
| Digital only (eShop / App) | **10 calendar days** before cycle start | Cycle start date |
| In-store price change with shelf talker, no leaflet | **7 calendar days** before cycle start | Cycle start date |
| Flash (in-store and/or digital) | **3 working days** before the Flash start date | Flash start date |
| Member mechanics (`MEMBER_PRICE`, `BONUS_POINTS`) | Digital cut-off **plus** Loyalty configuration lead time of 10 days | Cycle start date |

> Change note: the Flash cut-off was reduced from 5 to 3 working days in this version following the PromoHub express-release upgrade in July 2026. SOP WTCHK-COM-SOP-014 will be updated at its next revision.

## 4. Working-day calendar (for Flash cut-offs and service levels)

Working days are Monday–Friday excluding the following general holidays in the period: 1 Oct 2026 (Thu), 19 Oct 2026 (Mon, day following Chung Yeung), 25 Dec 2026 (Fri), 26 Dec 2026 (Sat), 1 Jan 2027 (Fri). This list is simplified for the demonstration.

**Worked example — Flash cut-off.** A Flash promotion starting Saturday 3 October 2026 must be approved by Tuesday 29 September 2026: counting back three working days from 3 October gives Friday 2 October (1), Wednesday 30 September (2, skipping the 1 October holiday), Tuesday 29 September (3).

## 6. Blackout periods

No price file releases on 3–4 January 2027 (annual stocktake). No Flash promotions in the 48 hours before a cycle start to avoid double price changes in stores.
